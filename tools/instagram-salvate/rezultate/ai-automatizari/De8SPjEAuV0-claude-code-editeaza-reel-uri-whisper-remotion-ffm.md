## Pe scurt
Fluxul: Claude scrie întâi un storyboard (replică, ce e pe ecran, ce unealtă); Whisper dă timing-ul fiecărui cuvânt pentru subtitrări; un model de segmentare decupează persoana ca textul să stea în spatele capului; Remotion face grafica animată; FFmpeg face corecția de culoare și efectele.

## Idei cheie
- Storyboard înainte de editare
- Whisper pentru subtitrări sincronizate

## Pași de aplicat
1. Scrie storyboard-ul ca tabel
2. Transcrie cu Whisper
3. Generează subtitrări și grafică cu Remotion
4. Culoare și tranziții cu FFmpeg

## Resurse menționate
| Resursă | Tip | Link | La ce folosește |
|---|---|---|---|
| Remotion | github | https://github.com/remotion-dev/remotion | Video din cod (React) |
| Whisper | github | https://github.com/openai/whisper | Transcriere cu timing pe cuvinte |
| FFmpeg | unealta | https://ffmpeg.org | Procesare video |
