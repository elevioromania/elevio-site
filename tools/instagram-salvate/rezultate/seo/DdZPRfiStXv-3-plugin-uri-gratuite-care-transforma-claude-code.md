## Pe scurt
Nick Saraev recomandă trei unelte gratuite: un MCP pentru Google Search Console (Claude citește datele și găsește cuvintele cheie unde ești aproape de top), OpenSEO (alternativă gratuită la Ahrefs/Semrush: keyword research, rank tracking, backlinks, audit) și GEO Optimizer Skill (optimizare ca ChatGPT, Claude și AI Overviews să citeze site-ul).

## Idei cheie
- Search Console + Claude = găsești cuvintele unde ești pe pozițiile 8–20 și știi ce să repari
- Uneltele open-source înlocuiesc abonamentele Ahrefs/Semrush pentru un site mic
- Mutarea importantă: să fii recomandat de AI, nu doar să rankezi în Google

## Pași de aplicat
1. Conectează Google Search Console la Claude printr-un MCP
2. Cere-i să găsească interogările unde ești aproape de prima pagină și ce trebuie reparat
3. Folosește OpenSEO pentru cercetare de cuvinte cheie, urmărire poziții, backlinks și audit
4. Rulează GEO Optimizer pe site ca să vezi dacă e pregătit să fie citat de AI
