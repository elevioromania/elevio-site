| Termen | Ce înseamnă |
|---|---|
| Lead | O afacere pe care o poți contacta. |
| Persoana de contact | Cel care ia decizia: proprietarul sau managerul. |
| Gatekeeper | Persoana care răspunde prima (de obicei recepția) și decide dacă ajungi la manager. |
| Demo | Numărul de test la care prospectul sună ca să audă agentul. |
| Setter | Tu: cel care programează întâlnirea. |
| Closing | Întâlnirea în care echipa de closing închide vânzarea. |
| Closer | Colegul din echipa de closing care ține întâlnirea și închide vânzarea. |
| Follow-up | Revenirea la un lead care n-a decis încă. |
| Obiecție | Motivul pentru care omul ezită. Se tratează, nu se combate. |
